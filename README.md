# Nexo — Resultados comerciais

Estudo de interface de um dashboard para acompanhamento de resultados comerciais, criado no Figma com apoio de inteligência artificial.

O projeto reúne receita, metas, indicadores e vendas recentes em uma tela desktop, com conteúdo em português e valores em reais.

## Sobre o projeto

O Nexo explora uma interface voltada a gestores e equipes comerciais que precisam acompanhar o desempenho das vendas.

A proposta é organizar informações de diferentes níveis: uma visão geral dos indicadores, a comparação entre receita e meta e os detalhes de pedidos recentes.

Este repositório documenta o estudo de design desenvolvido no Figma.

## O que compõe a interface

### Visão geral

- Navegação entre Visão geral, Vendas, Clientes, Metas e Relatórios.
- Campo de busca e seleção de período.
- Barra lateral com atalhos.

### Indicadores comerciais

- Quantidade de pedidos.
- Ticket médio.
- Taxa de cancelamento.
- Percentual de realização da meta do semestre.

### Gráficos

- Evolução mensal da receita.
- Comparação entre valores realizados e metas.
- Distribuição da receita por canal: loja virtual, loja física e parceiros.

### Vendas recentes

- Identificação do pedido.
- Canal de venda.
- Data e horário.
- Status com diferenciação visual.
- Acesso visual aos relatórios.

### Assistente Nexo

Conceito de assistente com ações para analisar resultados e gerar resumos, apresentado com dados simulados.

O arquivo também inclui estados de interface para filtros, seleção de período e detalhes de pedidos.

## Direção visual

A composição combina superfícies claras com painéis escuros em verde, destacando o gráfico de receita e o assistente.

- **Hierarquia:** indicadores principais em destaque e informações complementares em segundo plano.
- **Cores:** lilás, verde e amarelo para diferenciar séries, canais e informações.
- **Componentes:** repetição de cartões, botões, ícones e indicadores de status.
- **Organização:** separação entre análise de desempenho e consulta de vendas.
- **Formato:** tela principal desktop de 1440 × 900 pixels.

## Processo de criação

O projeto foi desenvolvido como um estudo de adaptação de uma referência visual, com apoio de IA na construção da interface no Figma.

O processo envolveu:

1. Seleção da referência visual.
2. Definição do contexto de acompanhamento comercial.
3. Orientação da geração por prompts sobre composição, hierarquia e componentes.
4. Adaptação do conteúdo para português e dos valores para reais.
5. Avaliação visual do resultado e organização da apresentação.

A referência serviu como base para o estudo da composição. O projeto não é apresentado como uma criação visual inteiramente original.

## Ferramentas

- **Figma:** construção e organização das telas.
- **Inteligência artificial:** apoio à criação orientada por prompts.
- **GitHub:** documentação e apresentação do projeto.

## Escopo do estudo

Este é um projeto de interface para portfólio, com dados fictícios.

Não inclui backend, integração com plataformas de vendas ou serviço de inteligência artificial em funcionamento. Os indicadores demonstram a apresentação visual dos dados e não representam resultados de uma empresa real.
